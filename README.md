# Análise de consumo de bebidas

Projeto desenvolvido em Python para comparar o consumo de `DRINKS` e `SOFT DRINKS` em duas unidades de restaurante.

## Objetivo

- Calcular o total de pessoas atendidas por unidade.
- Comparar as unidades vendidas por categoria.
- Calcular o consumo médio por pessoa atendida.
- Identificar os cinco produtos mais vendidos de cada grupo.

## Tecnologias

- Python
- Pandas
- Matplotlib
- Jupyter Notebook
- Excel

## Principais resultados

| Unidade | DRINKS por pessoa | SOFT DRINKS por pessoa |
|---|---:|---:|
| Anália Franco | 1,03 | 0,72 |
| Barra Shopping | 0,05 | 1,07 |

Anália Franco apresentou maior consumo de `DRINKS`, enquanto o Barra Shopping teve maior consumo de `SOFT DRINKS`.
